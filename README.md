### 🚀 How to Use This Dashboard
1. Download `Swiggy_Instamart_Dashboard.pbix`
2. Open in Power BI Desktop - Free version works
3. Use left panel filters to slice data by Year/Size/Tier
4. Hover on visuals for tooltips with exact numbers

---

### 💡 My Approach
1. **Data Cleaning**: Removed nulls, standardized Shop Type names, created Date column from Year
2. **DAX Measures**: Created measures for Total Sales, Avg Sales, Order Count, Rating Avg
3. **Visualization**: Chose bar for categories, donut for % split, line for trend - best chart per data type
4. **Storytelling**: Layout follows Z-pattern: KPIs → Breakdown → Trends → Table for detail

### 🎓 What I Learned
- How to design KPI cards that recruiters notice in 3 seconds
- DAX for dynamic Avg_Sales = Total_Sales / Total_Orders
